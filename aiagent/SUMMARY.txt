🎯 WHAT IS AN AI AGENT?
================================================================================

Simple: AI that can THINK and USE TOOLS

Flow:
   Question → LLM Thinks → Selects Tool → Executes Tool → Answers

Example:
   You: "Calculate 100 * 50"
   Agent: (decides to use calculator) → 5000

Tools Available:
   1. web_search   - Find information online
   2. calculator   - Do math safely  
   3. time        - Get current time

💡 KEY INSIGHTS:
================================================================================

1. Agents are decision-makers using tools
   - Tool descriptions help agents choose correctly
   - Multiple tools can be chained together

2. LLM is the brain
   - Understands questions
   - Decides what to do
   - Reasons about results

3. Tools are the hands
   - Do actual work (search, calculate, etc.)
   - Return results to agent
   - Agent uses results to answer

4. Safety is important
   - Validate all inputs
   - Sandbox tool execution
   - Handle errors gracefully

5. Testing helps
   - Try each tool independently
   - Verbose mode shows thinking
   - Test edge cases
