### ⚙️ Configuration Files

```
requirements.txt
├── Purpose: Python package dependencies
├── Use: pip install -r requirements.txt
└── Contains: langchain, openai, duckduckgo-search, python-dotenv

.env.example
├── Purpose: Template for your GitHub token
├── Use: Copy to .env and add your token
└── Security: Add .env to .gitignore (don't share!)

.env (CREATE THIS)
├── Purpose: Store your GitHub token
├── Security: Never commit to git
└── Content: GITHUB_TOKEN=ghp_your_token_here

setup.sh
├── Purpose: Automated project setup
├── Use: bash setup.sh
└── Does: Install dependencies, create .env template
```
