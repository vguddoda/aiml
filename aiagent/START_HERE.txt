📋 3-STEP SETUP:

   Step 1: Get GitHub Token (2 min)
   ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
   1. Go to: https://github.com/settings/tokens?type=beta
   2. Click: "Generate new token"
   3. Permission: Check "read:packages"
   4. Copy: Token starts with "ghp_"


   Step 2: Setup Project (1 min)
   ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
   Terminal:
   $ bash setup.sh


   Step 3: Add Token (1 min)
   ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
   Terminal:
   $ nano .env

   Edit the file:
   - Change: GITHUB_TOKEN=your_github_token_here
   - To:     GITHUB_TOKEN=ghp_your_actual_token_here
   - Save:   Press Ctrl+O, Enter, Ctrl+X
